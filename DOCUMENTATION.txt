bool ConsolMatrix_init(int x, int y):
if something is wrong, returns false
else return true
x - x size of Matrix
y - y size of Matrix
Use it to initialize ConsolMatrix


bool ConsolMatrix_deinit()
if something is wrong, returns false
else true
Use it to deinit ConsolMatrix


bool ConsolMatrix_drawPixel(int x, int y, unsigned char stateR, unsigned char stateG, unsigned char stateB)
if something is wrong, returns false
else true
x - x coordinate of pixel
y - y coordinate of pixel
stateR/stateG/stateB - RGB colors in 0-255 values
Use it to draw pixel when you know x and y


bool ConsolMatrix_drawPixelA(int buffer_address, unsigned char stateR, unsigned char stateG, unsigned char stateB)
if something is wrong, returns false
else true
buffer_address - address of pixel
stateR/stateG/stateB - RGB colors in 0-255 values
Use it to draw pixel when you know pixel address and you don't want to calculate it to x,y



bool ConsolMatrix_fillAll(unsigned char state)
if something is wrong, returns false
else true
state - color of Gray (R is State, G is State, B is State) in 0-255 values
Use it to fill Matrix with color.

bool ConsolMatrix_refreshMatrix()
if something is wrong, returns false
else true
Use it to refresh Matrix (if you do DrawPixel or DrawPixelA it doesn't refresh Matrix)
It can make artefacts.
It fixes artefacts 1/10 at a time.

bool ConsolMatrix_refreshMatrixAndFix()
if something is wrong, returns false
else true
Use it to refresh Matrix (if you do DrawPixel or DrawPixelA it doesn't refresh Matrix)
It fixes artefacts.


Warnings:
Use on terminals with ANSI Escape TRUECOLOR handling, else you will see like [38;2;255;255;255 and blocks (without color)
Don't use ConsolMatrix without initializing
Don't end program without deinit
